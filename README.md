1.Clone the repository: git clone https://github.com/PanSkoczyslaw/Fluid-Simulation-in-Pygame/tree/Vector-field. \
2.Go to the directory: cd Fluid-Simulation-in-Pygame. \
3.[On windows] Open cmd and create venv:
python -m venv "venv_name" \
4.Still in directory's cmd activate the virtual environment: \
"venv_name"\Scripts\activate. \
5.Install the packages: pip install -r Requirements.txt.
